An offline, open-source trophy guide and tracker for Grand Theft Auto VI on PlayStation 5 — an entry for the [make.fun bounty gta6-trophy-guide-01](https://make.fun/bounty/gta6-trophy-guide-01).

## What it is

- **55/55 trophies · every step cited · 13 sources** — the full official list (1 Platinum, 2 Gold, 6 Silver, 46 Bronze, 28 hidden), each with a guide in our own words, steps, and named sources.
- **Tracker** — check trophies off, saved in your browser (localStorage), with export and import, filters by grade and kind, text search, and a spoiler setting that hides story trophies until earned.
- **Roadmap** — four stages to the platinum, about 200 hours, with per-stage progress.
- **Missables** — the one missable trophy (Positive Mental Attitude) flagged loudly, with a Leonida map marking its region.
- **Offline** — plain static files, system fonts only, no network requests, no Rockstar artwork or logos.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Build the dossier

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Sources

PowerPyx, PushSquare, KeenGamer, Exophase, PSNProfiles, TrueTrophies, PlayStationTrophies.org, IGN, GameSpot, Polygon, Eurogamer, TheGamer, Game8. Trophy names, descriptions and grades are the official PlayStation 5 list of 2026-11-18. Guides are written in our own words.
